# 0.7.5 Windows / macOS 千往界面预览自动更新版

日期：2026-10-13。两端使用同一套千往设计语言；已从手动测试交付推进到预览自动更新，开启「接收预览版」即可检查本版。

## 已完成

- Mac 菜单栏将 CX 等缩写换成 Claude、Codex、Cursor 品牌图标，同时显示百分比与微型进度条。支持开关进度条，陈旧状态保留额度并标记。
- Mac 展开面板改为双栏总览与 Cursor 横排，设置直接替换当前页面；常规为 640×590，按实际原生卡片高度扩大或重排，不使用滚动容器。Plus 同时含 Credits/重置次数以及 17 个 Claude 行的夹具均验证。
- Windows 新增默认 ChoseWay 原生界面、可点击设置页、密码 Cookie 输入、键盘返回；任务栏缩略条使用品牌图标/进度，点击可打开独立完整面板并保留任务栏驻留。
- Windows DPI 绘制与命中测试采用同一坐标变换；独立面板 DPI 不改变任务栏 DPI；浮窗/缩略切换恢复样式与位置。旧配置仅首次迁移主题/自动尺寸，采集、启动、更新等设置保留。
- 完整面板保留实际额度窗口，Tokens 与额度分开；今日/昨日缺失显示未知，近七天汇总注明是否仅有部分日期。
