# Usage Monitor 0.7.4 Mac 自动更新测试版（2026-10-13）

本版仅交付 Apple Silicon（M 系列）Mac，要求 macOS 13+。Windows 预览仍为 0.7.3，稳定推荐仍为 0.6.2。

## 安装与更新

1. 将 `UsageMonitor-0.7.4-arm64-unsigned-updates.dmg` 复制到 Mac 本机，打开并将 `Usage Monitor.app` 拖入 Applications；覆盖前退出旧版。
2. **0.7.3 没有配置更新源，必须手动安装本版一次。** 之后菜单内可检查更新、自动检查/下载、选择预览通道；当前两通道基线均为 0.7.4，暂无更高版本。
3. 程序使用公开 GitHub HTTPS 源获取更新；只公开二进制和签名清单，应用源码保持私有。下载及安装前由 Sparkle 验证 Ed25519 签名，更新清单本身也要求签名。
4. 本包是 ad-hoc 应用签名测试包，**未做 Apple Developer ID 签名与公证**；更新签名不等同于 Apple 公证。首次启动若被系统拦截，在确认来自团队后，按 [Apple 说明](https://support.apple.com/zh-cn/102445)到「系统设置 → 隐私与安全性 → 仍要打开」。
5. 成员设置与 Cookie 仍在本机 `~/Library/Application Support/UsageMonitor/`，更新替换 App，不将成员凭证上传到下载服务。
