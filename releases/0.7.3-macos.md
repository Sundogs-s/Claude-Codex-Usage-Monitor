# Usage Monitor 0.7.3 Mac 测试安装包（2026-10-13）

文件：`UsageMonitor-0.7.3-arm64-unsigned.dmg`（2,434,452 字节），仅 Apple Silicon（M 系列），macOS 13 或更新版本；不支持 Intel Mac。

## 安装与首次启动

1. 将 DMG 复制到 Mac 本机，双击打开，把 `Usage Monitor.app` 拖入 `Applications`。
2. 从 Applications 启动，点击菜单栏的 Usage / CX 查看用量；可打开独立浮窗。
3. 本包使用 ad-hoc 签名，未配置 Developer ID 和 Apple 公证。若提示无法验证开发者，在确认来自本团队共享目录后，按 Apple 文档到「系统设置 → 隐私与安全性 → 仍要打开」允许本应用：[Apple 操作说明](https://support.apple.com/zh-cn/102445)。
4. Claude / Codex 需要在该 Mac 登录相应 CLI；Cursor 使用成员自己的 Cookie。登录与设置仅保存在成员本机。
