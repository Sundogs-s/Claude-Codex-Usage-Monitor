# Usage Monitor 0.7.6 Windows 主题弹窗与多显示器（2026-10-21）

2026-10-21 用户真机验证通过并要求推送给所有用户：Windows 稳定与预览通道均推进到 0.7.6（`latest.json`、`update-windows.json`、`preview.json`、`preview-windows.json`、根目录 README）。0.7.1 及以上版本可在托盘「软件更新」中自动准备并安装；0.6.x 及更早版本没有自动更新能力，需手动安装一次本目录安装包。Mac 无新二进制，Mac 稳定 / 预览 feed 不变。设计依据 `_Documentation/Design/windows-popup-v1/`。

## 变更

- 千往 Bar 每个平台最多两行「窗口名 · 微型进度 · 百分比」：Claude 5h / 7d、Codex 按实际窗口（Pro 仅 7d 时单行）、Cursor AUTO / API。修复 Claude Pro 只显示单一最高值。列宽 144，随 DPI 缩放。
- Classic / Neon 主题在任务栏模式下点击 Bar 或托盘图标，弹出各自主题的总览 / 设置弹窗；三个主题的弹窗在点击外部、切换到其他窗口或 Esc 时关闭，关闭后立即点 Bar 不会重开。
- 任务栏模式按所选显示器定位到该屏任务栏（副屏避让时钟）；显示器列表主屏优先并标注分辨率，面板设置中单击循环切换。旧版保存的「显示器 N」可能因排序变化指向另一块屏，切换一次即可。
- 弹窗 / 千往设置补充 5 秒刷新档；退出改为二次确认；千往设置文案「菜单栏」改为「任务栏」；悬停高亮在鼠标离开后清除。

## 真机复测

1. 退出旧版后运行本目录安装包，或把 `usage-monitor.exe` 复制到本机固定目录运行。设置与登录沿用本机数据。
2. 千往主题 + 嵌入任务栏：Claude Pro 应显示 5h / 7d 两行；分别开关 Codex、Cursor 和「Bar 缩略进度条」看列宽与排版。
3. 点击 Bar 弹出面板 → 点桌面、点其他程序、按 Alt+Tab、按 Esc 都应关闭；面板打开时再点 Bar 应收起且不再弹出；设置页 Esc 先回总览；在 Cookie 输入框右键菜单不应关闭面板。
4. 切换到 Neon、Classic 主题重复第 3 步；在弹窗设置里切换主题、刷新档、浮窗/任务栏模式，确认弹窗跟随更新且退出需确认。
5. 多显示器：托盘「高级设置 → 显示器」或面板设置切到副屏，Bar 应出现在副屏任务栏、不压住副屏时钟；面板应在该屏弹出。切回主屏验证恢复。
6. 若异常，反馈 `%LOCALAPPDATA%\UsageMonitor\_runtime_logs\usage-monitor.log` 中 `[appbar]`、`[menu]` 行、Windows 版本、显示器数量与缩放比例。
