# Usage Monitor 0.7.1 自动更新预览（2026-10-10）

Windows 新增自动检查/准备更新与一键安装重启；Mac 提供 Sparkle 自动更新接入源码及构建/发布脚本。
**旧版需先手动升级一次到 0.7.1**，之后托盘右键 → 软件更新。默认稳定通道，预览版本需勾选「接收预览版」。

## 行为

- Windows 启动约 15 秒后检查，此后每小时一次；后台复制并验证大小/SHA-256，准备好新版后通知一次。安装由用户点击「安装更新并重启」启动。
- 安装版使用 NSIS，保留旧程序备份与成员配置；正常 UAC 仍由 Windows 处理，结束后由成员权限的助手重启。
- 便携版自动替换本机 `usage-monitor.exe`，新程序在启动检查期间退出时恢复并重启旧版。UNC 共享路径运行需先复制至本机固定目录。
- NAS 不可达时继续运行现有版本；只接受更高版本，稳定/预览清单独立。软件更新不调用任何模型。
- Mac 固定使用 Sparkle 2.10.0，提供自动检查/下载、预览通道、Ed25519 包签名验证及替换重启。正式构建需 Developer ID、公证、公开密钥与 HTTPS 更新地址；当前无 Mac 环境，仍仅交源码。
