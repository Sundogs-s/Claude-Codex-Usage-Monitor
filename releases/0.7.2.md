# Usage Monitor 0.7.2 Win11 任务栏测试预览（2026-10-12）

修复 Win11 下选择 AppBar 却显示在任务栏上方的问题：取消 Win11 强制使用独立贴边摘要条，恢复优先挂到主任务栏内部、通知区左侧。仅挂载失败或 Explorer 不可用时临时回退摘要，并定时重试。

## 安装与测试

1. 退出旧版后运行 `UsageMonitor-0.7.2-Setup.exe`；便携版将 `usage-monitor.exe` 复制到本机固定目录再运行。
2. 托盘右键选择「嵌入任务栏 (AppBar)」。预期监控条显示在任务栏内部，不再浮在任务栏上方，Tokens / Credits 保持两行列对齐。
3. 检查开始按钮、任务栏图标、通知区和时钟仍可点击；切换到浮窗再切回 AppBar，切换服务显示开关及两种主题。
4. 按实际使用环境测试任务栏居中/左对齐、100%/125%/150% 缩放、自动隐藏、全屏及休眠恢复；记录是否有遮挡、裁切、消失或重新浮起。

若仍浮在任务栏上方，可能进入挂载失败回退。请记录 Windows 版本/build、缩放比例、任务栏对齐方式及截图；本机日志路径为 `%LOCALAPPDATA%\UsageMonitor\_runtime_logs\usage-monitor.log`。
