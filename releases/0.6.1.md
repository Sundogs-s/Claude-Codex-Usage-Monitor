# Usage Monitor 0.6.1

发布日期：2026-10-10。适用 Windows x64。

- 任务栏的 Tokens 与 Credits 两行合并为一行，例如：`25.6M tok 10/09 | 100 cr`。
- Tokens 数值放大加粗；日期、单位和分隔符使用灰色小字；Credits 用较柔和的蓝灰色区分。
- 合并后的两行布局放大额度百分比，日期仍明确标识统计归属。
- Neon HUD / Classic 两套主题均支持；浮窗继续展示完整统计。
- 采集逻辑沿用 0.6.0，只读查询不发送模型请求。

## 使用
运行 `UsageMonitor-0.6.1-Setup.exe` 升级；便携版可复制 `usage-monitor.exe` 至本机固定目录。
每位成员使用自己的平台登录，日 Tokens 可能存在服务端统计延迟。
