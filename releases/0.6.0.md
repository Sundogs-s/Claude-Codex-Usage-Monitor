# Usage Monitor 0.6.0

发布日期：2026-10-10。适用 Windows x64。

- Codex 自动识别套餐与真实额度窗口；Pro / Pro Lite 隐藏 5h，无周额度时不保留空行。
- 展示只读获取的每日 Tokens、Credits、套餐与更新时间；统计延迟时明确显示最近统计日期。
- 新增右键「Codex 用量详情」：全部额度、可用重置次数、最近 7 个已返回日期的 Tokens 与累计量。
- 查询失败保留旧数据并标记 stale / partial；同一账户才允许复用历史统计。
- Neon HUD / Classic 的浮窗与任务栏支持纯数值行；托盘不再把主额度误认为 5h。
- Codex 采集只调用账户、额度和统计读取接口，不发送模型请求，不消耗模型 Tokens 或重置券。

## 使用
推荐运行 `UsageMonitor-0.6.0-Setup.exe` 安装；也可将 `usage-monitor.exe` 复制到本机固定目录后运行。
每位成员使用自己的 Claude / Codex / Cursor 登录；日统计需要较新的 Codex CLI 或桌面版。无需团队共享凭证。
DAY 为服务端有当前日期记录的日统计；LAST 为最近返回的日期。没有今日记录不代表今日使用量为 0。
本版本不自动替换当前正在运行的旧版，安装程序负责升级。SHA-256 见同目录 SHA256SUMS.txt。
