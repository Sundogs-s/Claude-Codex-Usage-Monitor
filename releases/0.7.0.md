# Usage Monitor 0.7.0 预览（2026-10-10）

本版交付 Windows 预览安装包/便携版，以及 Apple Silicon Mac 源码和构建脚本。Mac 未编译、未生成 DMG；团队推荐版仍为 0.6.2。

## 变化

- Windows 11 自动把任务栏模式切换为独立贴边摘要条，保留已确认的 Tokens 左对齐、Credits 右对齐及日期弱化排版；Windows 10 继续嵌入任务栏。
- 增加 DPI、显示器/工作区变化、Explorer 恢复与休眠恢复处理；负坐标屏幕与屏幕移除时限制窗口可见。Win11 摘要条增加前台无标题栏全屏遮挡时暂时隐藏。
- 采集核心从 Windows UI 分离；新增 Mac 本地路径、原生 CLI 查找与 Claude Keychain 只读适配。
- Mac 原生源码包含菜单栏、悬浮窗、服务开关、手动刷新、用量详情、Cursor Cookie、登录启动、断线重试和退出清理。Pro 自动隐藏 5h、真实缺失值与只读 Codex 查询共用同一核心。
- 增加 arm64 原生构建、DMG、Developer ID 签名/公证脚本及手动构建工作流。默认测试包明确标记 unsigned，正式分发需签名、公证与真机验证。

## 验证

- Windows 10 x64 19045：`cargo test --locked` 12 项通过，含两主题 GDI 离屏渲染、Pro 过滤、缺失值、通信字段限制、布局边界测试。
- 首次通信测试发现无参数命令忽略额外字段（`bridge_rejects_unknown_actions_and_fields ... FAILED`），改用空结构命令后复测通过。
- 独立进程集成：服务/刷新设置、Cookie 保存与清除、不回显凭证、超长帧拒绝、EOF 取消采集通过；全程临时配置，无在线请求。
- Windows Release 与 NSIS 打包通过；91 条现有 Win32 返回值/未使用代码类警告，无编译错误，第三方依赖未升级。
- Mac 脚本 `bash -n` 通过，非 Darwin/arm64 环境拒绝执行符合预期；Info.plist 结构与版本检查通过。

## 未验证与取用

- 无 Win11 真机，贴边摘要、多屏混合 DPI、全屏、Explorer 重启、休眠恢复仍待真实系统回归。
- 按用户确认，本轮没有 Mac 构建环境；Swift/Rust Mac 编译、Keychain 权限、登录项、签名/公证、Gatekeeper 均未实际执行。
- 本轮未重跑在线 Claude/Codex/Cursor 采集，未安装或替换运行中的程序，未推送 GitHub或触发远程构建。
- 团队预览：`N:\PROJECTS\AI\UsageMointor\v0.7.0`；安装包 `UsageMonitor-0.7.0-Setup.exe`、便携 `usage-monitor.exe`、源码 `UsageMonitor-0.7.0-macOS-arm64-source.zip`，校验见 SHA256SUMS.txt。
- 源码 ZIP 的 `_Documentation/PlatformSupport.md` 提供 Mac 环境准备、构建与后续真机验证步骤。
