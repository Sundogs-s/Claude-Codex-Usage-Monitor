# Project Guide

## 项目定位
本项目是一个用于在 Windows 桌面端实时显示 Claude Code 与 Codex 用量的桌面工具。

## 核心目标
提供稳定、低延迟、可持续运行的用量可视化能力，帮助用户随时掌握 Claude Code 与 Codex 的实时使用状态。

## 设计原则
- 实时性优先：保证用量数据展示及时、可感知。
- 多形态展示：支持悬浮窗、任务栏嵌入等多种展示方式。
- 轻量与稳定：降低资源占用，保证长期运行稳定性。
- 可维护性：代码结构清晰，便于后续迭代与问题修复。

## 目标平台
- Windows 桌面端。

## 当前阶段
- 已完成初版开发。
- 当前处于问题修复与稳定性改进阶段。
